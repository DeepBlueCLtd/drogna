Feature 114 · design, before the build

The tabs beyond Operator

Three displays that do not exist yet, drawn before they are built: the traffic display, the holdings timeline, and the derived comparison of a forecast against the truth. This is a mockup and not a screenshot — every figure in it is invented, which is exactly what a mockup is for and exactly what the running shell may never do.

The vocabulary

Four kinds of figure

Feature 113 fixed three and made them visually distinct. Feature 114 adds the fourth, for a number the shell computed from documents it was served (ADR-0036). The treatments are the ones the stylesheet will carry.

the four treatments
declared6 s reported1 284 rows observed37 msg/s derived0.412 °C RMS
kindwhere the number came fromtreatment
declaredthe configuration documentboxed, thin outline
reporteda message the component publishedsolid left rule
observedcounted by the shell from traffic it receiveddotted underline

The rule that admits the fourth. The shell may transform documents it was served; it may not invent a figure no document contains. Every input crossed the seam, the reader can re-derive it from URLs on screen, and the panel says what it did.

Messages · built first

The traffic display

Lanes are the declared top-level namespaces of the topology artefact. A mark is one received message, placed by arrival. The display is the yardstick made visible: stop the sensors from Operator and the observation lane goes still while the clock lane beats on.

Each lane's marks decay to nothing as they age out of the window; the decay is the only thing that moves, and it stops when arrivals stop.

Holdings

The store's timeline

Not a list in arrival order: a timeline in simulation time, each holding drawn at the interval its own manifest says it covers. Three lanes, one per era. The archive spans twenty years and an instance spans hours, so the panel states the scale it is showing rather than letting a reader infer it from tick spacing.

And one deletion

System folds away

Six tabs become six again only because nothing replaces the seventh. The Operator flow chart has drawn every declared component greyed until heard since 113, which is FR-16's whole obligation. Two facts System carried alone move first:

legend · a grey node is a component that has not run yet, or has stopped — the display cannot tell you which, only the silence

#/view/system is just gone. No redirect and no tombstone: an address that resolves is a claim the thing still exists. A gate holds the shell to naming no view the configuration does not declare, so the next withdrawal cannot leave a dangling link unnoticed — planted, watched failing, reverted.

What this drawing is not

Every number here is invented

That is what a mockup is for and what the running shell may never do. In the shell each of these figures carries the treatment that says where it came from, and a figure with no source has nowhere to be drawn. drogna is a demonstration harness: its data is synthetic and its numerics are deliberately fake.
