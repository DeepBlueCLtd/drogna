== Egress from inside a container
   No proxy variables are set inside containers. TLS is intercepted transparently
   at the network layer, for every host tried — the no_proxy list the host tools
   read does not apply. Without the CA every fetch fails 'certificate verify
   failed'; with it, every one of the same hosts answers 200.
   /root/.ccr/ca-bundle.crt is a COMPLETE bundle:
     152 certificates, public roots included
   SSL_CERT_FILE already points at it, which is why deploy/README.md's line works
   verbatim: export HARNESS_PROXY_CA_FILE="$SSL_CERT_FILE"
